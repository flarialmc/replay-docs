# Editing Workflow

Good order saves rework.

## 1. Choose story

Write one sentence: “Show fight from approach to final hit.” If shot does not support it, remove shot.

## 2. Mark useful moments

Watch replay once. Add markers for action starts, key hits, quiet gaps, and ending.

## 3. Build rough sequence

Set start/end. Add camera cuts and basic poses. Ignore perfect easing.

## 4. Fix timing

Shorten dead space. Make action readable. Decide replay-speed changes.

## 5. Smooth camera

Tune paths, rotation, FOV, then easing. Fewer keyframes first.

## 6. Add world overrides

Time, weather, visibility only where they improve clarity or mood.

## 7. Add audio

Import, align, set volume/fades. Recheck cuts against beats or narration.

## 8. Review

Watch without touching controls. Then review:

- Camera collisions
- Sudden speed changes
- Hidden subjects
- Weather/time jumps
- Audio drift
- Beginning and ending frames

## 9. Save versions

Use simple names:

```text
fight-edit-v01
fight-edit-v02-camera
fight-edit-v03-audio
```

Do not overwrite only working version before big change.

## Shot checklist

For each shot ask:

1. What is subject?
2. Where should viewer look?
3. Why does camera move?
4. Why does shot end?

No answer → simplify or cut.
