# Glossary

**Audio clip** — placed range referencing imported audio file.

**Bézier curve** — curve shaped with control handles.

**Camera path** — route camera follows through world.

**Cut** — instant change between camera poses/shots.

**Discrete value** — state that switches rather than blends, such as visible/hidden.

**Ease in** — slow start, faster finish.

**Ease out** — faster start, slow finish.

**Field of view (FOV)** — how wide camera sees.

**Frame** — one displayed image at point in time.

**Graph** — visual map of value or speed over time.

**Handle** — control used to shape curve near keyframe.

**Hold keyframe** — keeps previous value until instant change.

**Interpolation** — how values/path fill gap between keyframes.

**Keyframe** — saved property value at chosen time.

**Marker** — note attached to time; does not change replay.

**Non-destructive** — edit instructions leave original replay/audio unchanged.

**Playhead** — line showing current sequence time.

**Property** — editable value such as camera X, FOV, or rain amount.

**Replay time** — position inside source replay.

**Sequence time** — position inside edited result.

**Shot** — continuous camera view between cuts.

**Snap** — automatically align times to frames, markers, or nearby keys.

**Spatial interpolation** — path shape through world space.

**Temporal interpolation** — value speed through time.

**Timeline** — tracks arranged against time.

**Track** — row containing one subject/property or audio.

**Waveform** — picture of audio loudness over time.

**Work range** — selected timeline section for preview/output.
