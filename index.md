## Experimental feature

Replay support is under active development. Current builds require **Minecraft for Windows 1.26.30 or newer**. Behavior may change while the feature is being tested.

Flarial Replay stores network and world activity in a `.flrreplay` file. It does not create a video. Use screen-recording software if you need a finished video file.
