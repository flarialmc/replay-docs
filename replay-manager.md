# Replay Manager

Open **Replays** from the top-left of Minecraft's title screen.

## Find and select replays

Replay cards show replay name plus recorded world or server name when available. Open **Settings** to see recording date, filename, and file size.

Use search to match names or metadata. Switch between **Newest** and **Oldest**, or click **Refresh** after adding a replay file manually. `F5` also refreshes the manager.

Select a replay card, then click **Play**.

## Manage a replay

Each replay has three action buttons:

| Action | Result |
| --- | --- |
| Settings | View metadata and rename the replay |
| Folder | Reveal the `.flrreplay` file in File Explorer |
| Trash | Ask for confirmation, then move the file to the Recycle Bin |

Replay names follow Windows filename rules. Names cannot contain `< > : " / \\ | ? *`, use reserved device names, or end with a space or period.

## Record button states

| Label | Meaning |
| --- | --- |
| **Record next world** | Arm recording for the next world or server joined |
| **Cancel recording** | Disarm the pending recording |
| **Stop recording** | Finalize and save an active recording if it remains active on the title screen |
